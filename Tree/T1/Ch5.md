## for문 a -> b 1씩 증가
- for loop의 포맷 : for (초기화식 ; 조건식 ; 증감식) { 반복할 코드 }
    - 초기화식 : for loop의 초기조건을 정해주게 된다.
    - 조건식 : 조건식에 해당하는 경우에만 for loop를 진행하게 된다.
    - for loop의 반복코드를 한번 진행한 경우 증감식에 의해 반복코드를 진행한 횟수가 세어진다.
    - 예 : for (int i = a; i < b; i++) { 반복할 코드 }
- 증감식에서는 i += c 형태의 코드가 일반적으로 들어가며, c의 값이 1인 경우 i++로 바꿔줄 수 있다.
    - 즉 i++은 i += 1과 같은 코드이다.
- 처음에 i 값이 초기화식에 의해 a로 설정되고, 조건식이 맞을 때에만 반복문이 진행된다.
- for문이 한번 실행될 때마다 증감식에 의해 i값이 1씩 늘어나게 된다.
- 초기조건이 i = a였기 때문에, 1씩 값이 늘어나다가 i = b가 되면 반복코드를 실행하지 않고 for loop를 탈출하게 된다.
- if조건문처럼 for내부라는 범위를 명확히 정의하기 위해 중괄호 { } 를 사용한다.
- 따라서 for 안에 포함되어야 하는 코드라면 중괄호 블록 내부에 코드를 작성해야 한다.

<br>

### Side Note
- if문에와 마찬가지로, 만약 for loop 내부임을 나타내는 중괄호 블록이 없다면 for ( ) 이후 단 한줄의 코드만 for loop 내부 코드로 인정된다.
    - for (int i = 5; i < 7; i++)
    - System.out.println(i);     // for 내부 코드
    - System.out.println(i * 2); // for 내부 코드가 아님
- a부터 b까지의 수에 공백을 두고 출력하는 것도 가능하다.
    - for (int i = a; i <= b; i++) {System.out.print(i + " ")};
<br>

### Side Note
- 변수 i를 1 증가시키는 코드는 i++ 외에도 ++i 도 있다.
- i++은 ++이 i 뒤에 있기 때문에 후위 증가연산자라고 한다. ++i 는 전위 증가연산자라고 한다.
- 이 둘의 차이 : 증가 연산자가 속한 줄의 코드가 실행되는 것과 증가 연산이 이루어지는 것 사이의 순서가 달려 있다.
- 전위 연산자인 ++i를 실행할 경우 그줄 코드를 실행하기 전에 증가가 이루어진다.
- 후위 연산자의 경우 코드실행이 먼저 이루어지고 증가가 이루어지게 된다.

## for문 a -> b 2씩 증가
- 증가하는 숫자가 1에서 2로 바뀐 것이므로, for loop의 증강문을 고쳐주면 된다.
- 예 : for (int i = 5; i < 11; i += 2)

<br>

## for문 a -> b 1씩 감소
- 숫자를 1씩 감소시키며 출력하는 프로그램은 증감문을 고쳐주면 된다.
- i -= C 를 이용할 수 있는데, C가 1일때는 i-- 를 써줄 수 있다.

<br>

## while문 a -> b 1씩 증가
- 숫자를 한 줄에 하나씩 출력하는 프로그램을 for loop가 아닌 while을 사용해 해결할 수도 있다.
- while은 항상 조건과 같이 쓰이며, while 안의 코드는 해당 조건을 만족하는 경우에만 반복하여 수행하는 형태를 띈다.
- while 포맷 : while (조건) { 여기에 조건을 만족할 때만 수행되었으면 하는 코드를 작성 }
- for loop처럼 while 내부라는 범위를 명확히 정의하기 위해 중괄호 { } 를 사용해줘야 한다.

<br>

### Side note
- while loop 역시 내부를 나타내는 중괄호가 없다면, 조건 이후 한줄의 코드만이 내부로 인정된다.
- 예 : while (i < 7)
    - System.out.println(i);     // while loop 내부 코드
    - System.out.println(i * 2); // while 외부 코드
    - i++;                       // while 외부 코드

<br>

### Side note
- do-while loop도 존재한다.
- while loop와 크게 차이가 없으나, 해당하는 반복문을 조건과 상관 없이 무조건 한번 실행한다는 차이점이 있다.
- 즉, 조건을 먼저 따지는 while loop와는 달리 반복문을 한번 실행한 후에 조건을 따져보게 된다.
- 포맷 : do { 여기에 조건을 만족할 때만 수행되었으면 하는 코드를 작성, 무조건 한번은 실행됨 } while (조건);

<br>

## while문 a -> b 2씩 증가
- 숫자를 2씩 뛰며 출력하는 프로그램은 while loop 안에서 증감값을 설정하는 부분의 코드만 2씩 증가하는 것으로 바꿔주면 된다.
- 예 : while (i <= 10) { System.out.print(i); i++};
- 예 : while (i <= 10) { System.out.print(i); i += 2};

<br>

## while문 a -> b 1씩 감소
- 숫자를 1씩 감소시키며 출력하는 프로그램은 while loop에서 증감값을 설정하는 부분의 코드만 1씩 감소하는 것으로 바꿔줌녀 된다.
- 예 : while (i >= 5) { System.out.print(i); i--; }

<br>

## n번 반복하기
- 단순히 특정 코드 수행을 n번 반복하고 싶은 경우에는 for loop를 활용해 단순히 for 내의 코드가 n번 반복되도록 만들어주면 된다.
- 포맷 : for (int i = 1; i <= n; i++) { 반복을 원하는 코드 작성 } <br>
✓ 알게 된 부분 : double로 계산하면 정확한 값을 저장하는 게 아니라 가까운 값으로 저장한다.

## if 안의 for
- 숫자 n이 짝수인 경우에만 a부터 b까지의 숫자를 출력하는 프로그램은?
- n이 짝수라는 조건을 담을 수 있는 if와 a부터 b까지 숫자를 1씩 증가시켜주는 for를 활용해 해결할 수 있다.
- 이때, for은 if 조건을 만족할 때만 수행되어야 하므로 꼭 if의 { } 내부에 작성해야 한다.

<br>

<br>

### for문 안의 if문
- a부터 b까지의 숫자들을 순서대로 보며 짝수인 경우에는 1, 홀수인 경우에는 0을 출력하는 프로그램은?
- a부터 b까지 숫자를 1씩 증가시켜주는 for 안에 해당 숫자 i가 짝수인지에 대한 구분을 할 수 있는 if를 넣어 해결할 수 있다.
- 이때, if는 for 안에서 각각의 i에 대해 전부 수행되어야 하므로 꼭 for의 { } 내부에 작성해야 한다.

<br>

### while문 안의 if문
- a부터 b까지의 숫자들을 수서대로 보며 while 문을 사용해서, 짝수인 경우에는 1, 홀수인 경우에는 0을 출력하는 프로그램은?
- a부터 b까지 숫자를 1씩 증가시켜주는 while 안에 해당 숫자 i가 짝수인지에 대한 구분을 할 수 있도록 해주는 if를 넣어 해결할 수 있다.
- 이때, if는 while안에서 각각의 i에 대해 전부 수행되어야 하므로 꼭 while의 { } 내부에 작성해줘야 한다.

<br>

## cnt 활용하기
- a부터 b까지의 숫자들 중 짝수의 개수를 세는 프로그램은?
- 이 경우에는 0을 초기값으로 값는 cnt라는 변수를 활용해, for 안에서 i 값이 짝수일 때만 cnt 값을 1씩 증가하는 식으로 진행할 수 있다.
- cnt를 꼭 0으로 초기화하고 진행해야 함에 유의해야한다.

## for문 a -> b 1씩 증가
- for loop의 포맷 : for (초기화식 ; 조건식 ; 증감식) { 반복할 코드 }
    - 초기화식 : for loop의 초기조건을 정해주게 된다.
    - 조건식 : 조건식에 해당하는 경우에만 for loop를 진행하게 된다.
    - for loop의 반복코드를 한번 진행한 경우 증감식에 의해 반복코드를 진행한 횟수가 세어진다.
    - 예 : for (int i = a; i < b; i++) { 반복할 코드 }
- 증감식에서는 i += c 형태의 코드가 일반적으로 들어가며, c의 값이 1인 경우 i++로 바꿔줄 수 있다.
    - 즉 i++은 i += 1과 같은 코드이다.
- 처음에 i 값이 초기화식에 의해 a로 설정되고, 조건식이 맞을 때에만 반복문이 진행된다.
- for문이 한번 실행될 때마다 증감식에 의해 i값이 1씩 늘어나게 된다.
- 초기조건이 i = a였기 때문에, 1씩 값이 늘어나다가 i = b가 되면 반복코드를 실행하지 않고 for loop를 탈출하게 된다.
- if조건문처럼 for내부라는 범위를 명확히 정의하기 위해 중괄호 { } 를 사용한다.
- 따라서 for 안에 포함되어야 하는 코드라면 중괄호 블록 내부에 코드를 작성해야 한다.

<br>

### Side Note
- if문에와 마찬가지로, 만약 for loop 내부임을 나타내는 중괄호 블록이 없다면 for ( ) 이후 단 한줄의 코드만 for loop 내부 코드로 인정된다.
    - for (int i = 5; i < 7; i++)
    - System.out.println(i);     // for 내부 코드
    - System.out.println(i * 2); // for 내부 코드가 아님
- a부터 b까지의 수에 공백을 두고 출력하는 것도 가능하다.
    - for (int i = a; i <= b; i++) {System.out.print(i + " ")};
<br>

### Side Note
- 변수 i를 1 증가시키는 코드는 i++ 외에도 ++i 도 있다.
- i++은 ++이 i 뒤에 있기 때문에 후위 증가연산자라고 한다. ++i 는 전위 증가연산자라고 한다.
- 이 둘의 차이 : 증가 연산자가 속한 줄의 코드가 실행되는 것과 증가 연산이 이루어지는 것 사이의 순서가 달려 있다.
- 전위 연산자인 ++i를 실행할 경우 그줄 코드를 실행하기 전에 증가가 이루어진다.
- 후위 연산자의 경우 코드실행이 먼저 이루어지고 증가가 이루어지게 된다.

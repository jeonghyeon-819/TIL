## 사칙연산
- Java에서 자주 이용되는 사칙연산은 덧셈, 뺄셈, 나눗셈, 곱셈이다.
- 덧셈은 +, 뺄셈은 -, 곱셈은 * 을 사용한다.
- 나누기 연산 시 몫은 /, 나머지는 % 연산을 통해 구할 수 있다.
- 만약 5를 2로 나누는 경우처럼 나누어 떨어지지 않는 경우는 나눗셈을 진행해 그 결과를 실수 값으로 받고 싶으면 반드시 실수 type이 들어있어야 한다.

<br>

### Side Note1
- 코드 : int a = 9, b = 4;
- 코드1 : System.out.println((double)a / b);
- 코드2 : System.out.println((double)(a / b));
- 코드1 답 : 2.25
- 코드2 답 : 2.0
- / 연산시 만약 연산이 이루어지는 두 항이 모두 정수형인 int 라면 그 결과는 정수(몫)이 나온다.
- 따라서 실수로 계산된 결과를 얻고 싶다면 꼭 double을 이용해야 한다.
- 정수형 변수, int type 변수인 a를 실수형 type인 double로 바꾸는 것은 (double)a 와 같이 할 수 있다.
- 두 type이 모두 실수형일 필요는 없고, 실수형과 정수형 간의 연산에서는 결과가 실수형이 나오기 때문에, 두 type 중 하나만 실수형으로 바꿔주면 된다.
- (double) a / b는 double로 계산이 되지만, (double) (a/b)는 a/b가 int(몫:2) 로 계산된 후, double로 type을 바꿔줬기에 결과값이 2.0가 된다.

<br>

### Side Note2
- 코드 : double a = 1 + 3.5; System.out.println(a);
- 답 : 4.5
- 사칙연산 계산시 type은 더 큰 범위를 따라가게 되어있기 때문에 (정수 < 실수), 정수와 실수가 만나면 계산결과의 type이 실수가 된다.

<br>

## 사칙연산 다른 표현법
- Java에서 사칙연산 이용시 보통 동일한 변수에 값의 변화를 주는 경우가 대다수이다.
- 예를 들어 변수 a에 들어있는 값에 5만큼 더 더해주고 싶은 경우에는 a = a+5; 작성 가능하다.
- 이런 경우가 자주 발생하기에 Java에서는 a += 5; 도 가능하다.
- 이는 곱하기, 나누기, 나머지 등의 모든 연산자에 적용 가능하다.<br>
✓ 알게 된 부분 : System.out.println((a % b) + " " + (a % (a % b))); 에서 오류가 나는 수는 a = 10, b = 5이다. <br>
✓ 이유 : a % (a % b) 일 때 10 % 5가 0이 된다. Java에서 정수의 나머지 연산에서 0으로 나눌 수 없기에 오류가 발생한다. <br>
✓ 즉, %의 오른쪽 값이 0이면 오류가 난다.

<br>

## 합과 평균
- 예시 : int a = 9, b = 4; System.out.println((a+b) + " " + ((double)(a + b) / 2));

### Side Note
- int a = 9, b = 4; System.out.println((double)a + b / 2);
- 사칙연산의 경우 수학에서와 같이 우선순위가 존재하기에 위의 문제일 때 b/2 먼저 계산하고 a를 더해주게 된다.

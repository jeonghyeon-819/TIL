## if 조건문
- 문제를 풀다보면 특정 조건에 해당하는 경우에만 코드를 수행하고 싶은 경우가 많이 생긴다.
- if 조건문의 포맷은 : if (조건) { 여기에 조건이 참일 경우에만 수행되는 코드 작성 }
- 여기서 if 내부라는 범위를 명확히 정의하기 위해 Java에서는 중괄호 블록 { } 을 사용한다.
- 즉, if문을 사용하게 되면 if 조건을 만족할 때, 해당 블록 내부에 있는 코드만을 실행하게 된다.
- 만약 { } 블록을 쓰지 않는다면 if 조건 다음에 나오는 오직 한 줄의 코드만 if 조건에 의해 실행된다.
- if 조건에 넣기 위한 비교 연산자는
    - a > b : a가 b보다 큰 경우에만 true
    - a >= b : a가 b보다 같거나 큰 경우에만 true
    - a < b : a가 b보다 작은 경우에만 true
    - a <= b : a가 b보다 같거나 작은 경우에만 true
    - a == b : a와 b가 동일한 경우에만 true
    - a != b : a와 b가 다른 경우에만 true
    - 같거나 큰, 혹은 같거나 작은 연산의 경우 등호 = 의 위치가 항상 비교연산 뒤에 나와야 함
    - 두 원소가 일치하는지는 꼭 = 문자 2개를 사용해야 한다.
    - == 기호는 값 뿐만 아니라 type도 일치해야 한다.

### Side Note
- 정수 a가 짝수인지 판별하기 위한 조건문은 % 연산을 사용해 2로 나눈 나머지가 0인지 비교하여 판단할 수 있다.
- 홀수인 경우에는 2로 나눈 나머지가 1인지를 판단하면 된다.
- % 연산을 이용하면 a가 n의 배수인지를 n으로 나눈 나머지가 0인지로 쉽게 판단이 가능하다.

## if else 조건문
- else 라는 구문을 이용하면, if 조건에 해당하지 않는 경우에만 특정 코드를 수행하게 할 수 있다.
- if else 포맷은 : if (조건) { 여기에 조건이 참일 경우메나 수행되는 코드 작성} <br>
                else { 여기에 조건이 거짓일 경우에만 수행되는 코드 작성 } <br>
                이 위치에 있는 코드는 조건과 무관하게 항상 수행된다.

<br>

## 삼항 연산자
- 정확히 if else로만 이루어져 있는 구문은 삼항연산자를 이용하면 한 줄에 표현이 가능하다.
- 삼항연산자 포맷 : if (조건) { a = V1; } else { a = V2; } -> a = 조건? V1 : V2;

<br>

### Side Note
- int a, n; n = 8; a = 2 + 6 + n < 10 ? 5 : 6; System.out.println(a);
- 이 결과는 6이다. 그 이유는 2 + 6 + n 부분이 하나로 묶여서 처리되어, 조건식이 n <2 가 되었기 때문이다.
- 만약 2+6을 상수로 더하고 삼항 연산자 조건 n < 10에 따라 5 또는 6이 선택되기 원했다면 ( ) 괄호를 이용해 코드를 작성해야 한다.

<br>

## if elif else 조건문
- else if 라는 구문을 이용하면, 상단 if 조건에 해당하지 않으면서 해당 else if 조건에 해당하는 경우에만 특정 코드를 수행하게 만들 수 있다.
- else 블록에서는 if 조건과 else if 조건에 모두 해당하지 않는 코드를 수행한다.
- 포맷 : if (조건1) { 코드 1 } else if (조건2) { 코드2 } else { 코드 3 } 코드 4
    - 조건1이 참이라면 코드1, 코드4가 수행된다.
    - 만약 조건1은 거짓이지만, 조건2는 참이라면 코드2, 코드4만 수행된다.
    - 조건1 조건2 모두 거짓인 경우에는 코드3, 코드4가 수행된다.
- if, else if 사용시 else case가 필요하지 않은 경우, else를 굳이 사용할 필요는 없다.
- if, if, else if를 사용하게 되면, 맨 끝에 있는 else if는 두 번째 if하고만 쌍을 이루게 된다.

<br>

## if elif elif else 조건문
- else if라는 구문은 여러 번 사용 가능하다.
- else if문을 여러 번 사용하게 되면, 각 else if 당 상단 if과 모든 else if에 걸리지 않으면서 해당 else if 조건에 해당하는 경우에만 특정 코드를 수행하게 만들 수 있다.
- 포맷 : if (조건1) { 코드1 } else if (조건2) { 코드2 } else if (조건3) { 코드3 } else { 코드4 } 코드 5
    - 조건1, 조건2가 모두 거짓이었는데 조건3이 참이라면 코드3, 코드5만 수행된다. <br>
✓ 알게 된 부분 : 문자열의 내용을 비교할 때는 .equals() 를 사용해야 한다. String text = sc.next(); text.equals(" ");

## if 조건문
- 문제를 풀다보면 특정 조건에 해당하는 경우에만 코드를 수행하고 싶은 경우가 많이 생긴다.
- if 조건문의 포맷은 : if (조건) { 여기에 조건이 참일 경우에만 수행되는 코드 작성 }
- 여기서 if 내부라는 범위를 명확히 정의하기 위해 Java에서는 중괄호 블록 { } 을 사용한다.
- 즉, if문을 사용하게 되면 if 조건을 만족할 때, 해당 블록 내부에 있는 코드만을 실행하게 된다.
- 만약 { } 블록을 쓰지 않는다면 if 조건 다음에 나오는 오직 한 줄의 코드만 if 조건에 의해 실행된다.
- if 조건에 넣기 위한 비교 연산자는
    - a > b : a가 b보다 큰 경우에만 true
    - a >= b : a가 b보다 같거나 큰 경우에만 true
    - a < b : a가 b보다 작은 경우에만 true
    - a <= b : a가 b보다 같거나 작은 경우에만 true
    - a == b : a와 b가 동일한 경우에만 true
    - a != b : a와 b가 다른 경우에만 true
    - 같거나 큰, 혹은 같거나 작은 연산의 경우 등호 = 의 위치가 항상 비교연산 뒤에 나와야 함
    - 두 원소가 일치하는지는 꼭 = 문자 2개를 사용해야 한다.
    - == 기호는 값 뿐만 아니라 type도 일치해야 한다.

### Side Note
- 정수 a가 짝수인지 판별하기 위한 조건문은 % 연산을 사용해 2로 나눈 나머지가 0인지 비교하여 판단할 수 있다.
- 홀수인 경우에는 2로 나눈 나머지가 1인지를 판단하면 된다.
- % 연산을 이용하면 a가 n의 배수인지를 n으로 나눈 나머지가 0인지로 쉽게 판단이 가능하다.

## if else 조건문
- else 라는 구문을 이용하면, if 조건에 해당하지 않는 경우에만 특정 코드를 수행하게 할 수 있다.
- if else 포맷은 : if (조건) { 여기에 조건이 참일 경우메나 수행되는 코드 작성} <br>
                else { 여기에 조건이 거짓일 경우에만 수행되는 코드 작성 } <br>
                이 위치에 있는 코드는 조건과 무관하게 항상 수행된다.

# 출력
- java에서 System.out.print 라는 함수를 사용할 수 있다.
- 문자열은 " " 를 이용해 표현할 수 있다.
- 문장을 출력할 때는, " " 를 사용해야 한다.
- 특수 문자를 포함시키기 위해서는 해당 문자 앞에 \ 를 붙여주면 된다.
- 줄바꿈을 하기 위해서는 System.out.println 을 이용하면 된다.
    - 줄바꿈을 출력하기 위해 \n 문자를 이용할 수도 있다.
    - \n 는 new line을 의미하는 특수문자로, 한 줄을 띈다는 것
    - 문자열 출력시 해당 문자를 사용하게 되면 한 줄이 띄어지게 된다.
- System.out.print(println)를 이용해 숫자도 출력할 수 있다.
    - " " 안에 문자열 "3"을 넣어도 출력결과는 동일하게 보여진다.
- 공백을 두고 출력하기 위해서는 " " 문자열 내 공백을 두고 출력하면 된다.
    - 두 숫자 사이에 공백을 넣고 출력하고 싶다면 + 연산자와 " " 을 이어서 작성하면 된다.

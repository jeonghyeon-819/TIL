# 출력

## 기본 출력
- java에서 System.out.print 라는 함수를 사용할 수 있다.
- 문자열은 " " 를 이용해 표현할 수 있다.
- 문장을 출력할 때는, " " 를 사용해야 한다.
- 특수 문자를 포함시키기 위해서는 해당 문자 앞에 \ 를 붙여주면 된다.
- 줄바꿈을 하기 위해서는 System.out.println 을 이용하면 된다.
    - 줄바꿈을 출력하기 위해 \n 문자를 이용할 수도 있다.
    - \n 는 new line을 의미하는 특수문자로, 한 줄을 띈다는 것
    - 문자열 출력시 해당 문자를 사용하게 되면 한 줄이 띄어지게 된다.
- System.out.print(println)를 이용해 숫자도 출력할 수 있다.
    - " " 안에 문자열 "3"을 넣어도 출력결과는 동일하게 보여진다.
- 공백을 두고 출력하기 위해서는 " " 문자열 내 공백을 두고 출력하면 된다.
    - 두 숫자 사이에 공백을 넣고 출력하고 싶다면 + 연산자와 " " 을 이어서 작성하면 된다.

## 변수와 자료형
- 변수는 어떤 값을 담을 수 있는 일종의 공간
- Java에서 변수에 값을 담기 위해서는 적절한 자료형(Type)의 변수를 선언해 적절한 값을 넣어주어야 한다.
    - 정수 : int, long
    - 실수 : double
    - 문자 : char
    - 문자열 : String
- 정수형, 실수형에 해당하는 변수들 끼리는 간단한 사칙연산이 가능하다.
- Java에서 2개 이상의 변수를 선언할 때는 한 줄에 동시에 선언할 수 있다.
    - int a = 5, b = 9;
- 코딩 컨벤션(Coding Convention) : 규약을 안 지킨다고 오류가 나진 않지만, 모두와 협업하기 위해 정해놓은 일종의 약속
    - 각 언어, 회사 별로 코딩 컨벤션은 다양하다.
    - 일반적으로 함수명은 소문자로 시작해 새로운 단어가 시작될 때마다 대문자로 바꿔주는 CamelCase 방식을 사용
    - 같은 이름은 사용하지 않기를 권장

<br>

## 출력 형식
- 2가지 방법 사용 가능
    - 변수 포맷(%d, $s, ...) 과 System.out.printf
        - 문자열에 해당 변수의 type에 해당하는 포맷을 적어주고, 그 뒤에는 ,를 사이에 두고 필요한 변수를 순서대로 나열하는 식
        - 2개 이상의 변수를 한 문자열에 넣기 위해서는 ,를 여러 개 사용해서 변수들을 순서대로 나열하면 된다.
        - 예: System.out.printf("A is %d and B is %s\n", a, b);
        - 문자열은 %s, 문자는 %c, 정수는 %d, 실수는 %f 등으로 사용 가능.
    - System.out.print, System.out.println 이용
        - 문자열 내에 + 연산자로 변수들을 이어주면 차례로 출력할 수 있다.
        - 예 : int a = 5; String b = "apple"; System.out.println("A is " + a + " and B is " + b);

<br>

## 소수점 맞춰 출력
- 실수값을 갖는 변수의 경우 소수점 자리에 맞춰 출력하는 경우가 대다수이다.
- 이 경우 System.out.printf를 이용해 %.?f 형태로 포맷을 지정해주면 된다. <br>
✓ 헷갈린 부분 : a, b, c가 있을 때. System.out.printf("%.0f * %.6f = %.6f", a, b, c);

<br>

## 변수 값 변경
- 처음 변수에 값을 할당했다고 해도, 다시 다른 값을 할당할 수 있다.
    - 예: int a = 3; a = 7;

<br>

## 다른 변수로부터 값 변경
- 변수 a의 값에 다른 변수 b에 있는 값을 가져와 넣어주는 것 역시 가능하다.
    - 예: int a = 5, b = 3; a = b;

<br>

## 두 변수 값을 교환
- temp 라는 추가 변수를 사용해 두 변수 값을 교환할 수 있다.
    - 예: temp = a; a = b; b = temp;

<br>

## 변수값 동시에 복사
- 값을 넣어주는 = 연산을 chain 형식으로 이용하면 변수 c에 있는 값을 변수 a, b에 동시에 복사할 수 있다.
    - a=b=c 일때, 오른쪽에서부터 먼저 b에 c 값을 넣고, a에 b 값을 넣어주게 되므로 전부 c와 동일한 값을 갖게 된다.
